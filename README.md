# Proyecto Plataformas de Big Data para Data Science 4to bimestre 2026 (Magíster en Estadística)

* Caso de uso: Un sistema de recomendación integrado en la app que sugiere recetas de Food.com
según el desgaste físico del día (por ejemplo, más carbohidratos al hacer cardio o más proteínas
después de entrenar fuerza), respetando las restricciones alimentarias de cada persona. Así, ayuda al
usuario a decidir qué cocinar para recuperarse bien sin salirse de su dieta.
